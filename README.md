# Сайт курсов валют на автопилоте

Генерирует ~460 SEO-страниц (`USD в RUB`, `EUR в KZT`, …) с конвертером и таблицами сумм.
GitHub Actions каждый день сам берёт свежие курсы (open.er-api.com, без ключа) и публикует сайт на GitHub Pages. Хостинг бесплатный.

## Одноразовая настройка (≈15 минут, дальше без вмешательства)
1. **GitHub → Settings → Pages → Source: GitHub Actions.**
2. В `config.json` замените `site_url` на `https://<ваш-логин>.github.io/rembo` (или на свой домен).
3. Запустите workflow *Build and deploy* (Actions → Run workflow). Сайт появится по адресу из шага 2.
4. Отправьте `…/sitemap.xml` в Google Search Console и Яндекс.Вебмастер (ускоряет индексацию).
5. Монетизация — заполните в `config.json` то, что подключите:
   - `adsense_client` (`ca-pub-…`) — Google AdSense (автоматически создаётся и `ads.txt`);
   - `affiliate_url` — партнёрская ссылка (сервисы переводов, обменники, брокеры, VPN и т.п.);
   - `affiliate_banner_html` — готовый баннер партнёрки; `analytics_id` — GA4.

## Локально
`python3 generate.py --offline` → `dist/` (тестовые курсы).

## Честно о доходе
Это долгая игра: страницы индексируются недели–месяцы, доход на старте — единицы долларов в месяц и растёт с трафиком. Чтобы масштабировать, добавляйте валюты в `CURRENCIES` (и крипто/металлы) — страницы появятся сами.
