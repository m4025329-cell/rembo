# 🔒 Политика безопасности BlackLotusVPN

## Отчёт об уязвимости

Если ты нашёл уязвимость — **не открывай публичный issue** и не выкладывай
эксплойт. Напиши напрямую владельцу проекта в Telegram (см. README).

Все сообщения обрабатываются в течение 48 часов. После подтверждения
уязвимости — 7 дней на приватный фикс, потом раскрытие.

## Поддерживаемые версии

| Версия | Поддержка |
| ------ | :-------: |
| `main` |     ✅    |
| прочее |     ❌    |

## Что мы делаем

Полный список технических мер — в [`docs/SECURITY.md`](docs/SECURITY.md).
Кратко:

- Секреты только через `.env`, ни один секрет не хранится в коде.
- Секреты в БД (VPN-ключи, платёжные токены) шифруются Fernet.
- Все API-эндпоинты требуют подписанный Telegram `initData`.
- Rate limit на IP и anti-flood на юзера.
- Заголовки безопасности (HSTS, X-Frame-Options, CSP) на всех ответах.
- Аудит-лог всех админских действий.
- Pre-commit hook с gitleaks — запрещает случайно закоммитить секрет.
- Regular encrypted backups.

## Что от тебя как контрибьютора

- Никогда не пиши секреты в код, тесты, комментарии, коммиты.
- Прогоняй `pre-commit run --all-files` перед пушем.
- Скачивай зависимости только из официальных источников.
- Не логируй `BOT_TOKEN`, `FERNET_KEY`, VPN-ключи, платёжные данные.
- При взломе — действуй по [`docs/INCIDENT_RESPONSE.md`](docs/INCIDENT_RESPONSE.md).
